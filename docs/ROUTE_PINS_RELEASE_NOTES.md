# UMA v0.1.9 — Pandal and station pins

The group/trail itinerary and active navigation maps now use the same familiar pins as the original map: numbered pandal stops, metro station icons in line colours, and railway station pins. Metro stations between boarding and alighting points are included. The current pandal is highlighted, and tapping a pin shows the stop or station name.

Journey pins remain visible during walking guidance. Repeated stations are deduplicated and pandal pins are drawn above stations so the next visit is easy to select.

Android version: 0.1.9 (2007). Download `UMA-v0.1.9.apk`; `SHA256SUMS.txt` contains its checksum.

Validation: pending final build and device check.
