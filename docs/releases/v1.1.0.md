# UMA v1.1.0 - 3D maps and marker improvements

- MapLibre vector maps with bundled OpenFreeMap light and dark styles.
- Switch between flat maps and 3D buildings, with map label controls.
- Improved map camera restoration, viewport clustering and marker projection.
- Updated trail route overlays and incoming group call alerts.
- Includes the profile screen and previous photo, return-home and tracking updates.

## Android downloads

- `UMA-v1.1.0-arm64-v8a.apk`: recommended for most modern Android phones.
- `UMA-v1.1.0-armeabi-v7a.apk`: older 32-bit ARM devices.
- `UMA-v1.1.0-x86_64.apk`: compatible emulators and x86 Android devices.
- `SHA256SUMS.txt`: SHA-256 checksums for all three APKs.

App version: `1.1.0+4023`, signed with the existing release identity.
This release provides Android APKs; iOS and web packages are not included.
