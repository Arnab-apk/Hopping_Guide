# UMA v1.1.0 — Tested fixes, build 4025

Download **UMA-v1.1.0-universal.apk** for the latest tested Android app, version **1.1.0 (4025)**. It supports ARM64, ARM32 and x86_64 and uses the existing release signature.

## Fixes in this update

- Journey cards keep GPS follow, map settings and 2D/3D controls visible and tappable.
- Profile statistics use the loaded directory total: 347 pandals.
- Group calling backend fixes provider timeouts and small token clock differences. The server fix is deployed.
- Retains the 3D maps, place search, curated routes, return-home planner and shared hopping lists.

## Verification

- Installed and tested on a Motorola Edge 50 with existing account/group data preserved.
- Static analysis clean; 480 Flutter tests passed, five optional tests skipped in the standard run.
- Four live routing tests and 52 final UI checks passed.
- Phone camera, microphone mute and end-call verified; three synthetic clients received remote audio/video.
- A fresh test identity joined an existing group and read its complete 15-stop list through deployed client permissions. Temporary records removed.
- Six curated circuits resolve all their stops; 26 invite/shared-list/route tests and four invite-page tests passed.

Second physical-phone media/push delivery, outdoor arrival and full offline coverage remain unverified. Return-home last departures are unverified and labelled in the app.

## Downloads and compatibility

- **UMA-v1.1.0-universal.apk**: latest build 4025; recommended download (approximately 350 MiB).
- **SHA256SUMS.txt**: checksums for every APK attached to this release.
- The three architecture-specific APKs are retained **older builds** from 17 October, with version codes ARM32 5023, ARM64 6023 and x86_64 8023. They do not include this update. Android will reject build 4025 as a downgrade over those higher version codes; do not uninstall to bypass that restriction if you need to preserve app data.

The existing v1.1.0 tag is retained. Updated source is on the release/v1.1.0 branch.
