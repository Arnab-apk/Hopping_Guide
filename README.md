### 🗺️ 1. Interactive Regional Map & Auto-Fly
* **Keyless & Budget Safe:** Powered by `flutter_map` and OpenStreetMap raster tiles without costly Google Maps API billing or leakable keys.
* **Auto-Fly Camera Centering:** Tapping any zone instantly flies and zooms the map camera directly onto that region's cluster (e.g., jump 45 km north to Kalyani or 35 km to Chinsurah in 1 tap).
* **Responsive Region Selector:** Features a pinned `[ 📍 Regions ▾ ]` selector pill that never clips on mobile screens, plus an expandable bottom sheet grouped into **Kolkata Metro** and **Suburban Districts**.
* **Dual-Thumb Action Buttons:** Stacked floating buttons for 1-hand GPS centering and instant region switching.

### ⛩️ 2. Deep Pandal Directory & "Nearest to Me"
* **Comprehensive Details:** Timings, sabeki vs. contemporary themes, nearest metro and circular railway stations, crowd forecast badges, and curated descriptions.
* **Real-time GPS Distance:** High-precision Haversine distance calculations from the user's live device location.
* **Smart Search:** Instant searching across pandal names, areas, regions, and districts in both English and Bengali.
* **Offline-First Persistence:** Bookmark favorite pandals and maintain a personal "Visited" checklist using local storage.

### 🏛️ 3. Curated Hopping Circuits & Emergency Directory
* **Curated Trails:**
  * 🔴 **North Kolkata Heritage Walk:** Kumartuli Park, Bagbazar, Hatibagan, Kasi Bose Lane, Ahiritola.
  * 🟡 **South Kolkata Grand Circuit:** Ballygunge Cultural, Ekdalia Evergreen, Singhi Park, Maddox Square.
  * 🟣 **Bonedi Bari Trail:** Sovabazar Rajbari, Chatu Babu Latu Babu, ancestral household pujas dating to 1757.
* **Emergency Lifeline:** One-touch direct dialing to Kolkata Police (100), Ambulance (102), Fire (101), Women Helpline (1091), and Traffic Control.

## 🛠️ Tech Stack & Architecture

| Layer | Technology | Rationale |
|---|---|---|
| **Client Framework** | **Flutter 3 (Dart 3)** | Cross-platform, compiled native ARM performance, battery-efficient |
| **Map Rendering** | **flutter_map + OpenStreetMap** | Free raster tiles, zero API fees, no billing account needed |
| **Local Offline Cache** | **JSON Assets + SharedPreferences** | Instant boot, works with poor connectivity during crowded festival nights |
| **Device Geolocation** | **geolocator** | High-accuracy foreground GPS with battery-saving throttling |
| **Authentication (P0)** | **Firebase Auth + Google Sign-In** | Spark free tier, seamless guest fallback mode |
| **Live Squad Tracking (P0)**| **Firebase Realtime Database** | Low-latency ephemeral GPS sync (`/groups/{groupId}/locations`) |
| **Data Seeding & Scraper** | **Node.js + Cheerio** | Scrapes & normalizes pandals, food spots, events into JSON & CSV |

## 🚀 Getting Started

### Prerequisites
* Flutter SDK (3.13+)
* Android SDK (API 36, Build Tools 36.0.0)
* JDK 17
* Node.js 18+ (for scripts)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<OWNER>/<REPO>.git
   cd puja_proj
   ```

2. **Install Flutter dependencies:**
   ```bash
   cd app
   flutter pub get
   ```

3. **Verify environment health:**
   ```bash
   flutter doctor
   flutter analyze
   flutter test
   ```

4. **Run on connected phone or emulator:**
   ```bash
   flutter run
   ```
